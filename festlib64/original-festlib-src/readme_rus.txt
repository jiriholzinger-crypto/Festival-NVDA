Данное дополнение к программе экранного доступа NVDA позволяет ей использовать систему синтеза речи Festival.
Скопируйте содержимое каталога synthDriver в папку, где должны располагаться дополнительные пользовательские синтезаторы.
В данный архив включены два английских голоса, остальные английские голоса можно найти по ссылкам, приведенным в файле readme_eng.txt.
Для подключения русского голоса необходимо:
1. Скачать дистрибутив русского голоса с сайта www.festlang.berlios.de
2. Распаковать архив с голосом в каталог synthDrivers\festival\lib\voices\russian. Обратите внимание, что архив содержит *.tar файл. Сначала извлеките этот файл, затем распакуйте его.
После перезапуска NVDA и выбора Festival в качестве синтезатора в списке доступных голосов должен появиться русский голос msu_ru_nsh_clunits.
